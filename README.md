# ATM Simulation using Python & Tkinter

A simple and user-friendly **ATM Banking Simulation** built using **Python and Tkinter**. This project provides a graphical interface for performing basic ATM operations such as checking balance, depositing cash, and withdrawing cash.

## 📌 Description

This project is designed to simulate the basic functionality of an ATM machine through a GUI application. It was created as a Python practice project to improve programming logic, functions, GUI development, and user interaction.

## ✨ Features

* 💰 Check account balance
* 💵 Deposit cash
* 🏧 Withdraw cash
* ✅ Transaction success messages
* ❌ Error handling for invalid transactions
* 🖥️ Simple and user-friendly GUI
* 🔒 Fixed-size ATM interface

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **VS Code**
